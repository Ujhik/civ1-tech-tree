Copy and fill in for each technology in your tech tree:

```json
{
  "id": "",
  "name": "",
  "prerequisites": [],
  "buildings": [],
  "wonders": [],
  "units": [],
  "spaceshipParts": []
}
```

- `id`: Unique identifier for the tech
- `name`: Display name
- `prerequisites`: Array of tech IDs required to unlock
- `buildings`: Array of buildings unlocked
- `wonders`: Array of wonders unlocked
- `units`: Array of units unlocked
- `spaceshipParts`: Array of spaceship parts unlocked
